## ⚙️ How to Run

### 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Install Dependencies

```bash
cd frontend
npm install
```

### 3. Start React

```bash
npm start
```

### 4. Run PHP Backend

Start your PHP server and configure your MySQL database.
